Ubah Huruf Besar dan Kecil

Rapikan kapitalisasi teks tanpa mengetik ulang. Pilih bentuk huruf, ubah teks, lalu salin hasilnya.

Kapital awal membuat huruf pertama tiap kata menjadi besar. Singkatan dan merek seperti NASA atau iPhone bisa ikut berubah.

Batas masukan 100.000 code points dan 400.000 byte UTF-8. Teks diproses secara lokal di browser.

Hasil dapat disalin atau diunduh sebagai TXT. Maksimal hasil 800.000 byte UTF-8.

Siap mengubah teks di browser ini.

Cara menggunakan alat ubah huruf

  1. Ketik atau tempel teks pada kolom Teks awal.
  2. Pilih huruf besar, huruf kecil, atau kapital awal kata sederhana.
  3. Pilih Ubah huruf, lalu salin hasil atau unduh sebagai TXT.

Mode kapital awal kata membuat huruf pertama setiap kata besar, termasuk kata “dan”, “di”, dan “ke”. Contoh: halo dunia menjadi Halo Dunia. Ini perubahan format sederhana, bukan aturan penulisan judul bahasa Indonesia. Nama seperti NASA dapat berubah menjadi Nasa, dan iPhone menjadi Iphone.

Spasi, tab, tanda baca, angka, emoji, dan baris tetap seperti semula. Batas masukan adalah 100.000 code points dan 400.000 byte UTF-8; hasil maksimal 800.000 byte UTF-8. Browser biasanya menyimpan pemisah baris sebagai LF; unduhan memakai teks hasil yang sama.

Batas teks awal adalah 100.000 Unicode code points dan 400.000 byte UTF-8. Hasil maksimal 800.000 byte UTF-8. Masukan dan hasil diproses di browser; alat tidak mengirim teks ke server.

Pertanyaan umum

Apakah spasi dan baris baru ikut berubah?

Tidak. Logika mempertahankan whitespace dan baris. Textarea browser biasanya menyimpan newline sebagai LF; hasil dan unduhan berasal dari isi textarea yang diproses.

Apakah kapital awal mengikuti kaidah judul Indonesia?

Tidak. Setiap token yang diawali huruf mendapat kapital, tanpa pengecualian kata. Gunakan mode ini sebagai perubahan format sederhana.

Mengapa NASA menjadi Nasa?

Mode kapital awal lebih dulu membuat huruf lain menjadi kecil, lalu mengawali setiap token dengan kapital. Mode ini tidak mengenali singkatan atau merek.

Apakah teks dikirim ke server?

Tidak. Transformasi berjalan di browser dan alat tidak mengirim teks awal ke server.
