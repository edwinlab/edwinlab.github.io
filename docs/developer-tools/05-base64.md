# 05 — Base64 Encoder / Decoder

Status: selesai — encoder/decoder tersedia sebagai halaman statis; seluruh fixture lulus.
Model: **GPT-6 Luna (`gpt-6-luna`), reasoning `medium`**. Rekomendasi berdasarkan cakupan tugas, bukan benchmark.
URL: `/base64/`.

## Tujuan dan batas pekerjaan

Encode/decode teks UTF-8 dengan mode Base64 standar atau Base64URL yang eksplisit dan validasi input ketat.
UI dan konten publik berbahasa Inggris; jangan menggunakan `btoa(text)` langsung untuk teks Unicode.

**Batas teknologi:** hanya HTML, CSS, JavaScript vanilla dan library JavaScript lokal siap browser bila disebutkan. Tanpa npm, package.json, framework, bundler, transpiler, atau backend.

## Fixture dan tes wajib

- [x] Standard encode `Hello, world!` menghasilkan `SGVsbG8sIHdvcmxkIQ==`.
- [x] Standard decode `SGVsbG8sIHdvcmxkIQ==` menghasilkan `Hello, world!`.
- [x] Encode `✓` menghasilkan `4pyT`; decode mengembalikan karakter sama.
- [x] Standard encode `😀` menghasilkan `8J+YgA==`; Base64URL menghasilkan `8J-YgA`.
- [x] URL decode `8J-YgA` dan `8J-YgA==` sama-sama menghasilkan `😀`.
- [x] Standard decode `8J-YgA==` ditolak; URL decode `8J+YgA==` ditolak.
- [x] Encode `f`, `fo`, `foo` menghasilkan `Zg==`, `Zm8=`, `Zm9v`; bentuk URL `Zg`, `Zm8`, `Zm9v`.
- [x] Standard `Zg` ditolak karena padding hilang; URL `Zg` diterima sebagai `f`.
- [x] `A`, `Z=g=`, `Zg===`, `Zg==!`, dan `Z g==` ditolak sebagai malformed.
- [x] `Zh==` ditolak karena pad bits tidak kanonik; bentuk URL `Zh` juga ditolak.
- [x] `/w==` pada mode standar ditolak sebagai bytes UTF-8 tidak valid.
- [x] Teks dengan spasi/newline dan `日本語` lolos round-trip tanpa perubahan.
- [x] Empty encode/decode menghasilkan empty output; input melebihi 5 MiB menghasilkan error batas ukuran.
- [x] Payload teks HTML menghasilkan teks literal di browser; tidak mengeksekusi markup.
