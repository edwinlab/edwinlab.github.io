Kompres Gambar

Kompres gambar JPG atau PNG menjadi JPEG atau WebP. Atur kualitas, bandingkan ukuran file, dan unduh hasil dengan pemrosesan lokal di browser.

Maksimal 10 MiB, 12 juta piksel, dan 8192 px per sisi. Batas ukuran file menggunakan MiB (1 MiB = 1.048.576 byte); file diperiksa dari isi, bukan nama ekstensi.

Belum ada gambar dipilih.

JPEG mengisi area transparan PNG dengan latar putih. WebP hanya tersedia bila browser mendukung ekspor WebP.

Pilih bilangan bulat 60–95. Kualitas lebih tinggi dapat menghasilkan file lebih besar. Slider tidak mengompres otomatis.

Nama file hasil mengikuti format pilihan. Foto baru dibuat dari bitmap browser; sebagian metadata atau profil warna dapat berubah dan tidak dijamin tetap utuh. File tidak diunggah oleh alat ini.

Perbandingan hasil

Hasil lebih besar dari file asli. Coba kualitas lebih rendah atau gunakan file asli.

Ukuran byte di atas adalah ukuran file sebenarnya. KiB dan MiB memakai basis 1024. Dimensi piksel ditampilkan terpisah dari ukuran file.

Pilih satu file JPEG atau PNG untuk memulai.

Cara menggunakan kompresor gambar

  1. Pilih satu gambar JPEG atau PNG, atau muat contoh sintetis.
  2. Pilih JPEG atau WebP dan atur kualitas 60–95.
  3. Pilih Kompres gambar, bandingkan pratinjau serta ukuran, lalu unduh hasil jika sesuai.

File dan foto diproses di browser tanpa diunggah ke layanan kompresi. Batas input adalah 10 MiB, maksimal 12 juta piksel, dan maksimal 8192 piksel pada setiap sisi. File hasil dibatasi 20 MiB.

Ukuran file berbeda dari dimensi piksel

Ukuran file diukur dalam byte dan memengaruhi kebutuhan penyimpanan atau transfer. Dimensi seperti 1200 × 800 px adalah jumlah piksel gambar dan tidak diubah oleh tool ini. Contoh hitung: file 100000 byte menjadi 60000 byte berarti turun 40000 byte atau 40%; itu hanya aritmetika contoh, bukan janji setiap gambar akan mengecil sebesar itu.

JPEG dan WebP menggunakan kompresi lossy; perubahan kualitas dapat mengubah detail atau tampilan. Jika hasil lebih besar, tool tetap menampilkan dan mengizinkan unduhan hasil tersebut, tetapi menyarankan untuk mencoba kualitas lebih rendah atau memakai file asli.

Format dan transparansi

JPEG tidak mendukung transparansi. Saat PNG diekspor sebagai JPEG, area transparan diisi putih. WebP dapat mempertahankan alpha jika encoder browser mendukungnya; bila format tersebut tidak tersedia, tool menampilkan error dan meminta Anda memilih JPEG, tanpa menyamarkan JPEG sebagai WebP.

Ukuran hasil encoder native dapat berbeda antar browser. Pengkodean ulang dapat mengubah metadata atau profil warna, dan tool tidak menjanjikan penghapusan metadata secara forensik.

Pertanyaan umum

Apakah gambar saya diunggah?

Tidak. File dibaca dan diproses di browser pada halaman ini; tool tidak mengirim gambar untuk dikompres. Aset halaman tetap dimuat dari host website.

Apakah ukuran piksel berubah?

Tidak. Dimensi bitmap hasil tetap sama dengan gambar yang dibaca browser, termasuk orientasi foto yang didukung.

Mengapa file hasil bisa lebih besar?

Ukuran dipengaruhi format sumber, konten, kualitas, dan encoder browser. Gambar yang sudah efisien atau sangat kecil dapat menghasilkan file yang lebih besar setelah dikodekan ulang.

Bisakah saya menetapkan target 200 KB?

Tidak pada versi ini. Tool menyediakan pengaturan kualitas 60–95 dan membandingkan ukuran hasil; ukuran target pasti tidak dijanjikan.
