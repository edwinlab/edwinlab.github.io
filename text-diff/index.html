Text Diff

Compare two text drafts line by line and see what was added, removed, or left unchanged. Your text stays in this browser.

Combined input limit: 512 KiB UTF-8 and 5,000 line tokens. Textarea values normalize line endings to LF.

Tabs, spaces, blank lines, and final newlines are compared exactly.

Add two texts and select Compare text.

Comparison

How to compare text

  1. Paste the older text in Original text and the newer text in Updated text.
  2. Select Compare text. Added, removed, and unchanged lines appear with original and updated line numbers.
  3. Copy or download a plain-text report if you need to share the review.

For example, comparing status: pending with status: paid shows one removed line and one added line.

Comparison rules

This tool compares exact line tokens. It does not ignore whitespace, case, or Unicode normalization, and it does not detect moved lines. A replacement appears as a removed line followed by an added line. Final newline differences and line endings are shown explicitly.

The browser textarea API normalizes pasted line endings to LF, so the comparison reflects the text visible in these fields, not the original file bytes. The report is not a Git patch and cannot be applied automatically.

Limits and privacy

The combined input is limited to 512 KiB of UTF-8 text and 5,000 line tokens. A comparison runs in a local worker with a 4-second deadline and a bounded edit distance. Large or very different inputs may be rejected. No file upload, network processing, storage, or telemetry is used.

Is my text uploaded?

No. The comparison runs in a worker in this browser. The tool does not send or save either input.

Why do line endings differ?

Textarea values normalize pasted CRLF and CR to LF. For values created by the tool or test fixtures, line-ending tokens are compared separately.

Is the report a patch?

No. It is a readable review report, not a patch format.
