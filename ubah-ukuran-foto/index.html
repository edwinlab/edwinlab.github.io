Ubah Ukuran Foto

Perkecil dimensi foto JPG atau PNG berdasarkan lebar, tinggi, atau persen. Rasio foto tetap dijaga, dengan unduhan PNG, JPEG, atau WebP di browser.

Maksimal 10 MiB, 12 juta piksel, dan 8192 px per sisi. Batas ukuran file memakai MiB (1 MiB = 1.048.576 byte); isi file diperiksa, bukan ekstensi.

Rasio aspek dikunci dan dimensi selalu dihitung dari gambar asli. Pembulatan piksel dapat sedikit mengubah rasio angka pada gambar yang sangat kecil. Foto diproses di browser; sebagian metadata atau profil warna dapat berubah.

Perbandingan hasil

Dimensi piksel dan ukuran file byte adalah ukuran yang berbeda. Foto beresolusi lebih rendah belum tentu menjadi file yang lebih kecil.

Pilih satu file JPEG atau PNG untuk memulai.

Cara menggunakan pengubah ukuran foto

  1. Pilih satu foto JPEG atau PNG, atau muat contoh sintetis.
  2. Pilih lebar, tinggi, atau persentase dan masukkan angka bulat.
  3. Pilih format PNG, JPEG, atau WebP, lalu tekan Ubah ukuran.
  4. Bandingkan dimensi serta ukuran file dan unduh hasil jika sesuai.

Contoh: foto 1200 × 800 px dengan lebar 600 px menjadi 600 × 400 px. Tool memperkirakan dimensi lebih dulu, lalu membuat file baru hanya saat tombol ditekan.

Dimensi foto dan ukuran file

Dimensi seperti 1200 × 800 menunjukkan jumlah piksel. Ukuran file byte menunjukkan ruang simpan atau data transfer. Mengurangi dimensi tidak menjamin ukuran file menjadi lebih kecil karena format, isi gambar, dan encoder turut berpengaruh.

Rasio aspek dijaga dengan menghitung ulang dari gambar asli. Dimensi piksel harus berupa bilangan bulat, sehingga pembulatan dapat sedikit mengubah rasio angka pada gambar kecil. Tool ini tidak memperbesar foto.

Format, batas, dan pemrosesan

PNG mempertahankan transparansi tetapi proses resize tetap mengubah piksel. JPEG memakai kompresi lossy dan mengisi area transparan dengan putih. WebP mengikuti dukungan ekspor browser. File maksimum 10 MiB, 12 juta piksel, 8192 px per sisi; hasil maksimum 20 MiB.

File dibaca dan diubah di browser tanpa dikirim untuk diproses. Foto baru dapat memiliki metadata atau profil warna berbeda dari sumber.

Pertanyaan umum

Bisakah saya memperbesar foto?

Tidak. Nilai lebar dan tinggi dibatasi sampai dimensi asli, dan mode persen dibatasi sampai 100%.

Apakah foto dipotong?

Tidak. Tool mengunci rasio aspek dan tidak menyediakan crop atau peregangan.

Apakah file pasti lebih kecil?

Tidak. Dimensi baru lebih kecil, tetapi encoding foto dapat menghasilkan ukuran byte yang lebih besar atau lebih kecil.

Apakah foto diunggah?

Tidak oleh alat ini. File diproses di browser; aset halaman tetap dimuat dari host website.
