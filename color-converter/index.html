Limits and behavior

This calculator supports opaque sRGB only. It does not accept alpha, named CSS colors, display-P3, or OKLCH. HSL display is rounded to two decimals; contrast passes use the unrounded sRGB ratio. AA requires 4.5:1 for normal text and 3:1 for large text; AAA requires 7:1 and 4.5:1 respectively.

For example, #ff0000 is rgb(255, 0, 0) and hsl(0, 100%, 50%). AA and AAA thresholds depend on text size: large text is at least 18 pt regular or 14 pt bold. The ratio is calculated from full-precision sRGB luminance, so a displayed value rounded to 4.48:1 can still fail a 4.5:1 threshold.

Is my input uploaded?

No. Processing runs locally in this browser; this page does not send tool input to a server.

Frequently asked questions

Does this page upload or save my input?

No. The tool runs in your browser and does not place input in its URL or browser storage. Your browser may keep its own clipboard or download history if you use those features.

What happens when input is outside the supported format?

The page reports a validation message and keeps your input available to edit. Review the stated limits and examples before copying a result. Browser support and available memory can also affect processing time.

Can this replace a full development or security system?

No. This focused utility handles only the formats and operations described above. Validate important outputs in the application or workflow where you plan to use them.
